## Workshop Schedule

### 1. Coding in R - Basics

**Date:** 17. September 2025  
**Time:** 14:00 - 15:30  
**Speaker:** Luke Günther, _Project S, CRC 1252_

**Topics:**

- Introduction to R programming environment
- Basic data structures and operations
- Data import and export procedures
- Essential R packages for research
- Best practices for reproducible R code

---

### 2. Online Experiments

**Date:** 1. Oktober 2025  
**Time:** 14:00 - 15:30  
**Speaker:** Onur Özsoy, _Project C03, CRC 1252_

**Topics:**

- Designing and implementing online experiments
- Platform selection and setup (jsPsych, Prolific, MTurk)
- Participant recruitment and screening
- Data quality control in online studies
- Ethical considerations for online research

---

### 3. Archiving Session

**Date:** 15. Oktober 2025  
**Time:** 14:00 - 15:30  
**Speakers:** Luke Günther, _Project S, CRC 1252_ & Sarah Saleh, _Data Center
for the Humanities, UoC_

**Topics:**

- Long-term data preservation strategies
- Digital archiving standards and formats
- Institutional repository usage (UoC guidelines)
- Metadata creation and documentation
- Legal requirements for data archiving

---

### 4. Coding in Python/VSCode and LLMs

**Date:** 29. Oktober 2025  
**Time:** 14:00 - 15:30  
**Speaker:** Job Schepens, _Project S, CRC 1252_

**Topics:**

- Python development environment setup with VSCode
- Essential Python libraries for research (pandas, numpy, matplotlib)
- Version control integration with Git
- AI-assisted coding with Large Language Models
- Code quality and documentation best practices

---

### 5. Bayesian Regression Models

**Date:** 12. November 2025  
**Time:** 14:00 - 15:30  
**Speaker:** Job Schepens, _Project S, CRC 1252_

**Topics:**

- Introduction to Bayesian statistical thinking
- Bayesian vs. frequentist approaches
- Implementing Bayesian regression in R (brms, rstanarm)
- Prior specification and model checking
- Interpreting Bayesian results and credible intervals

---

### 6. Computational Reproducibility Session using R

**Date:** 26. November 2025  
**Time:** 14:00 - 15:30  
**Speaker:** Luke Günther, _Project S, CRC 1252_

**Topics:**

- Reproducible research workflows in R
- R Markdown and Quarto for dynamic documents
- Package management with renv
- Containerization approaches (Docker, renv)
- Version control best practices for R projects
- Creating reproducible analysis pipelines
