## Overview

Long-term data preservation strategies, standards, and institutional repository usage. We will cover metadata creation, documentation, and legal requirements for archiving research data.

## Learning Objectives
- Understand digital archiving standards and formats
- Plan for long-term preservation and accessibility
- Apply UoC repository guidelines effectively
- Create useful metadata and documentation
- Address legal and ethical considerations

## Topics Covered
- Long-term data preservation strategies
- Digital archiving standards and formats
- Institutional repository usage (UoC guidelines)
- Metadata creation and documentation
- Legal requirements for data archiving
