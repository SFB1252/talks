# Bayesian Regression Models

**Date:** 12. November 2025  
**Time:** 14:00 - 15:30  
**Speaker:** Job Schepens (Project S, CRC 1252)

## Overview

Introduction to Bayesian statistical modeling with a focus on regression. We will compare Bayesian and frequentist views, implement models in R, and interpret results.

## Learning Objectives
- Understand Bayesian vs. frequentist perspectives
- Implement Bayesian regression in R (brms, rstanarm)
- Specify priors and perform model checking
- Interpret posterior distributions and credible intervals

## Topics Covered
- Bayesian statistical thinking
- Regression modeling with brms/rstanarm
- Priors, diagnostics, and model checking
- Interpreting results and uncertainty
