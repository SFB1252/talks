## Overview

This workshop introduces the Shiny framework for creating interactive web applications directly from R code.

## Learning Objectives

- Understand Shiny application structure
- Build interactive user interfaces
- Implement reactive programming concepts
- Deploy Shiny applications

## Topics Covered

- Introduction to Shiny framework
- UI design and layout
- Reactive programming in Shiny
- Application deployment
- Best practices for Shiny development

## Prerequisites

- Intermediate R programming skills
- Familiarity with data visualization
- Basic HTML knowledge helpful but not required
