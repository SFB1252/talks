# Let's Rant: Open Debugging

**Workshop 19 - Winter Semester 2025-26**

## Overview

This interactive workshop provides a collaborative environment for debugging code and solving programming challenges together.

## Learning Objectives

- Apply systematic debugging strategies
- Interpret error messages effectively
- Use debugging tools in R and Python
- Develop problem-solving approaches

## Topics Covered

- Common debugging strategies
- Error message interpretation
- Debugging tools in R and Python
- Community problem-solving approaches
- Live debugging session

## Prerequisites

- Basic programming experience in R or Python
- Bring your own code problems (optional)
