## Overview

This session focuses on educating linguistics researchers about general data and coding licensing issues. We will explore the differences between open source software licenses and open data/content licenses, providing practical guidance on selecting appropriate licenses for different research outputs.

## Learning Objectives

- Understand what licenses are available for datasets, code, and teaching materials
- Determine which licenses are recommendable for specific academic use cases and why
- Distinguish between open source licenses and open data / content licenses
- Apply licensing principles to practical cases involving GitHub, OSF, repositories, and supplementary materials

## Topics Covered

### Introduction to Licensing in Research
- The necessity of explicit licensing for scientific reproducibility
- Key concepts of copyright and licensing

### Open Source vs. Open Data Licenses
- Software licenses (e.g., MIT, GPL, LGPL)
- Data/Content licenses (e.g., CC BY, ODC-By)

### Recommended Licenses
- Code: Permissive vs. Copyleft
- Data: CC0, CC BY
- Teaching materials: CC BY-SA

### Practical Case Study
- Code licensing and dependency conflicts (e.g., GPL-2 vs. LGPLv3)
- Data licensing bifurcation (e.g., restricted data vs. open software)
- Using the `ConversationAlign` package as an example

### Navigating Repositories
- GitHub and OSF licensing
- Journal supplementary materials
