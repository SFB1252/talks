## Overview

This beginner-friendly session introduces LaTeX as a writing environment for
academic documents. Participants will learn the basic structure of a document
and practice adapting a simple template.

## Learning Objectives

- Understand what LaTeX is and when it is useful
- Recognize the basic structure of a LaTeX document
- Work with sections, figures, tables, and references
- Start editing a simple article or handout template

## Topics Covered

- LaTeX basics and common use cases in academic writing
- Document structure and source files
- References, figures, and tables
- Working in Overleaf or with a local editor
