# Bayes Factor

**Workshop 20 - Winter Semester 2025-26**

## Overview

This workshop introduces Bayes Factors as a tool for model selection and hypothesis testing in Bayesian statistics.

## Learning Objectives

- Understand Bayes Factor methodology
- Interpret Bayes Factor values
- Compare nested and non-nested models
- Implement Bayes Factors in R

## Topics Covered

- Introduction to Bayes Factors
- Bayes Factor interpretation guidelines
- Model comparison techniques
- Computing Bayes Factors in R
- Advantages and limitations

## Prerequisites

- Basic knowledge of Bayesian statistics
- Familiarity with R programming
- Understanding of hypothesis testing
