# Bayesian Hypothesis Testing Using ROPE

**Workshop 14 - Winter Semester 2025-26**

## Overview

This workshop covers Bayesian hypothesis testing using the Region of Practical Equivalence (ROPE) approach.

## Learning Objectives

- Understand ROPE methodology
- Apply Bayesian hypothesis testing framework
- Define meaningful effect sizes
- Interpret ROPE-based decisions

## Topics Covered

- Region of Practical Equivalence (ROPE) concept
- Bayesian hypothesis testing framework
- Effect size specification
- Implementation in R with bayestestR

## Prerequisites

- Basic knowledge of Bayesian statistics
- Familiarity with R programming
- Understanding of hypothesis testing
